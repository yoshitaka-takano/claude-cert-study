# Claude Certification Study

Claude Certified Architect の受験準備用リポジトリ。

## 中身

| ファイル | 内容 |
|---|---|
| `index.html` | CCAR-P 模擬問題集アプリ（42問・全7ドメイン）。単一ファイルで完結し、オフラインでも動作 |
| `plan.html` | 受験日から逆算した学習計画とテストセンター当日の注意事項 |

## 使い方

GitHub Pages で公開されています。

- 問題集: https://yoshitaka-takano.github.io/claude-cert-study/
- 学習計画: https://yoshitaka-takano.github.io/claude-cert-study/plan.html

スマートフォンで開き、共有メニューから「ホーム画面に追加」すると、アプリのように起動できます。

## 問題集の仕様

- 問題文と選択肢は英語（本番試験に準拠）、解説は日本語
- `SELECT TWO` 表示の問題は2つ選択する形式
- 出題モード: 今日の10問（配点比率に沿った加重抽出）／ドメイン別／誤答の復習／全問通し
- 誤答と累計スコアはブラウザの localStorage に保存され、端末内にとどまります

## 注意

収録されている問題はすべて学習用に新規作成したオリジナルです。実際の試験問題ではありません。ドメイン配点・出題数・合格点は公開情報にもとづく参考値であり、公式 Exam Guide で確認してください。
